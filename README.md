# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using Python,
Pandas, NumPy and MySQL.

The project focuses on customer demographics, purchasing behavior,
product preferences, subscription status, discounts, payment
methods, and purchase frequency.

## Project Workflow

Raw Dataset
→ Python EDA
→ Data Cleaning
→ Feature Engineering
→ Cleaned Dataset
→ SQL Analysis
→ Power BI Dashboard
→ Final Project Report & Presentation

## Tools & Technologies

- Python
- Pandas
- NumPy
- MySQL
- Power BI
- Jupyter Notebook

## Project Files

| File | Description |
|---|---|
| `EDA.ipynb` | Python-based EDA, data cleaning and feature engineering |
| `customer_shopping_behavior.csv` | Original dataset |
| `customer_shopping_cleaned.csv` | Cleaned dataset used for SQL analysis |
| `customer_shopping_sql_queries.sql` | MySQL database setup and SQL analysis |
